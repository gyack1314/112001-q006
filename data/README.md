# 合成报文样本说明

本目录报文均为**合成数据,仅用于本地演练**,不代表任何真实厂商接口。

## 文件

- `messages.json` — 基础混合批次:v1 旧报文(标量容量,旧口径仅下行)与 v2 新报文
  (拆分 `{down,up}`、代际枚举、共享资源关系)混排;A-01 的 v1 报文有效期止于
  2026-02-28,v2 报文自 2026-03-01 起,演示同一资产跨 Schema 版本的期间衔接。
- `v1_backfill.json` — 离线系统补传的旧报文,含正常记录与三类问题记录
  (未知枚举 `NB-IoT`、缺 `capacity` 字段、有效期起止倒置),用于隔离诊断演练。
- `v2_batch.json` — 新版批次:共享资源上报(R-9 归属 SITE-1;R-10 未携带制式,
  规范标记为 MULTI)、正常资产、厂商扩展枚举 `5G-ADVANCED`(m1.0 下隔离,
  m1.1 下映射为 NR)、悬空共享引用 `R-LATE`(补传到达前隔离)、缺 `up` 分量。
- `v2_late_batch.json` — 补传批次:`R-LATE` 共享资源上报(解除 D-01 的悬空关系),
  以及与 `v1_backfill.json` 内容一致的 A-03 重传(演示幂等去重:不产生重复事实)。

## 口径备注

- v1 `capacity` 为单一数值,旧口径仅统计下行;v1 无上行字段,规范模型中
  `capacity_up = null`(未知,非 0)。
- v2 `capacity` 拆分为 `{down, up}`;`shared_resource` 为成员关系引用,
  共享容量按资源 `owner_scope` 归属口径计一次,成员资产不重复计入。
- 单位大小写不敏感;`Gbps` 归一为 `MBPS`(×1000);`Erlang` 不可换算,原样保留。
